# ✈️ Away Travel - Landing Page de Alto Padrão

Uma Landing Page responsiva, elegante e moderna desenvolvida exclusivamente para a agência **Away Travel**, com foco em conversão e venda de roteiros personalizados para destinos premium como **França (Paris)**, **Suíça** e **Grécia (Santorini)**.

O projeto foi totalmente refatorado e debugado, substituindo elementos estáticos por uma arquitetura interativa conectada diretamente à API de atendimento do WhatsApp e redes sociais.

---

## 🚀 Funcionalidades

- **Design Premium & Fluido:** Layout sofisticado construído com foco na experiência do usuário (UX/UI), destacando destinos aspiracionais em um carrossel dinâmico (`hero-slide`).
- **Engenharia de Conversão (CTAs Inteligentes):** Cards de destinos e blocos de serviços totalmente clicáveis e integrados com gatilhos que direcionam o cliente para o fechamento de orçamentos específicos.
- **Integração com APIs de Atendimento:** Botões de ação configurados dinamicamente com mensagens personalizadas automatizadas para o WhatsApp, facilitando o início do contato do usuário.
- **Rodapé Profissional:** Seção de contatos integrada com links estruturados para redes sociais (Instagram) e atualização automatizada do ano de direitos autorais via JavaScript.
- **Código Limpo e Otimizado:** Resolução de erros de requisição local (4xx Client Error) por meio do mapeamento e correção de rotas, caminhos de arquivos e tags HTML abertas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica, limpa e acessível.
- **CSS3:** Estilização moderna, efeitos de transição fluida (`transition`, `:hover`), efeitos de profundidade (`box-shadow`) e responsividade.
- **JavaScript (Vanilla):** Lógica para manipulação do carrossel, captação de dados do fluxo de cotação e automação de elementos de texto do sistema.
- **Netlify:** Plataforma utilizada para o deploy contínuo, publicação e hospedagem gratuita do sistema na nuvem.
